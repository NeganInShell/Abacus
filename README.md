# 🎮 چالش ریاضی | Math Challenge

بازی آموزشی ریاضی برای بچه‌های ابتدایی — یادگیری **ضرب ✖️، تقسیم ➗، جمع ➕، تفریق ➖** با بازی و هیجان!

> 🌐 کاملاً فارسی و راست‌چین (RTL) — بدون هیچ وابستگی خارجی

## 🕹 بازی آنلاین

بازی همین حالا از اینجا قابل دسترسیه — روی گوشی هم نصب می‌شه (PWA):

**https://negandinshell.github.io/Abacus/**

## ⚠️ هشدار حقوقی و شرعی

> **کپی‌برداری غیرقانونی از این اثر، بدون ذکر منبع و اجازه سازنده، پیگرد قانونی دارد و از نظر شرعی حرام می‌باشد.**

## ✨ امکانات

- 🎮 **۴ بازی جدا:** ضرب، تقسیم، جمع و تفریق — هر کدوم ماژول مستقل خودش رو داره
- 🌱 **۳ سطح سختی + مخلوط:** آسون، متوسط، سخت — انتخاب سختی اول هر بازی
- ⭐ **امتیاز و ستاره:** هر بازی ۱۰ سؤال، با ستاره‌گذاری بر اساس درصد
- 📊 **کارنامه:** خلاصه آمار + تاریخچه ۵۰ بازی آخر با نمایش سختی
- 🗑 **پاک کردن تاریخچه** با یک کلیک
- 🎨 **۳ تم رنگی:** 🐢 لاک‌پشت‌های نینجا | 🧽 باب‌اسفنجی | 🦇 بتمن
- 🖼 **شخصیت‌های SVG** دست‌ساز برای هر تم (بدون عکس خارجی)
- 😄 **ایموجی‌های شناور** و انیمیشن‌های فان
- 🎵 **صداهای فان** با Web Audio API
- 🎊 **کانفتی** موقع برد!
- 📲 **PWA:** نصب روی گوشی و کارکرد کامل **آفلاین**
- 📱 **کاملاً ریسپانسیو** — موبایل، تبلت و دسکتاپ

## 🚀 اجرا

روی گیت‌هاب پیجز آماده‌ست؛ ولی می‌تونی فایل `index.html` رو هم مستقیم در مرورگر باز کنی:

```bash
# یا با یک سرور محلی (اختیاری):
npx serve .
```

## 🗂 ساختار پروژه

```
├── index.html              # صفحه اصلی (تمام صفحه‌ها)
├── manifest.json           # مانیفست PWA
├── sw.js                   # سرویس‌ورکر (کارکرد آفلاین)
├── pwa.js                  # ثبت سرویس‌ورکر
├── icons/                  # آیکون‌های PWA
├── .github/workflows/      # دیپلوی خودکار روی گیت‌هاب پیجز
├── css/
│   ├── base.css            # استایل پایه و فوتر
│   ├── components.css      # دکمه‌ها، گزینه‌ها، سختی، کارنامه
│   ├── animations.css      # همه انیمیشن‌ها
│   ├── themes.css          # سه تم: نینجا، باب‌اسفنجی، بتمن
│   └── responsive.css      # ریسپانسیو برای همه دستگاه‌ها
└── js/
    ├── app.js              # فایل اصلی: راه‌اندازی و اتصال ماژول‌ها
    ├── questions.js        # سازنده سؤال‌ها بر اساس سطح سختی
    ├── game.js             # موتور مشترک بازی (چرخه سؤال و امتیاز)
    ├── storage.js          # ذخیره‌سازی (اسم، تم، تاریخچه)
    ├── sounds.js           # صداهای فان (Web Audio)
    ├── characters.js       # شخصیت‌های SVG هر تم
    ├── ui.js               # ابزارهای UI (صفحه، کانفتی، ایموجی)
    └── games/              # ═══ هر بازی، یک ماژول جدا ═══
        ├── multiply.js     # ✖️ ضرب
        ├── divide.js       # ➗ تقسیم
        ├── add.js          # ➕ جمع
        ├── subtract.js     # ➖ تفریق
        └── stats.js        # 📊 کارنامه
```
